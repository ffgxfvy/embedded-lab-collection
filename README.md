## 1. `51-password-lock/` — 电子密码锁系统

**任务**（课程综合实验"题目十"）：以 **AT89C52** 为核心设计电子密码锁。

**基本要求**：六位数字密码经 4×4 矩阵键盘设置并存入 **AT24C02 EEPROM**（掉电不丢失）；逐位输入时蜂鸣器提示 + **LCD1602** 显示状态；密码正确后 **16×16 LED 点阵**显示笑脸；记录每次成功解锁时间并支持历史查询。

**扩展实现**：密码修改（需先验证旧密码）、**DS1302 实时时钟**显示与设置、多级状态反馈（LED + 蜂鸣器）、菜单导航、各处操作的**超时自动返回**。

### 软件架构

**有限状态机，8 个状态**：

| 状态 | 说明 |
|---|---|
| 空闲 | 等待输入 |
| 确认旧密码 | 修改密码流程第 1 步 |
| 设置新密码 | 修改密码流程第 2 步 |
| 解锁成功 | 显示笑脸 + 记录时间 |
| 错误 | 密码错误提示 |
| 设置成功 | 新密码已写入 EEPROM |
| 查看记录 | 历史解锁时间查询 |
| 时间设置 | 手动设置 RTC |

各状态间有明确的转移条件与**超时自动返回机制**。

### 关键算法与工程取舍

| 实现 | 说明 |
|---|---|
| 密码验证 | 逐位比较，O(n) |
| 时间记录存储 | **循环队列**，最多保存 5 条，新记录覆盖最旧 |
| 键盘消抖 | **状态机消抖**（而非延时函数），不阻塞主循环 |
| 定时基准 | 定时器 0 中断提供 **1 ms** 基准，中断内完成系统计时、按键扫描、LED 点阵刷新 |
| **内存优化** | AT89C52 内部 RAM 仅 256 字节 → 用 **`idata` 扩展区**存放 `password[6]`、`stored_password[6]`、`DS1302_TIME` 等数组与结构体；常量表用 **`code` 关键字**放程序存储器 |

```c
// main.c 片段
idata uchar password[6];          // 工作密码（idata 扩展 RAM）
idata uchar stored_password[6];   // 存储密码
idata DS1302_TIME setting_time;   // RTC 设置结构体
```

### 硬件接线

| 外设 | 连接 |
|---|---|
| LCD1602 | 数据口 P0；控制线 P2.5–P2.7 |
| 4×4 矩阵键盘 | P3 口 |
| DS1302 RTC | P1.0–P1.2（三线） |
| AT24C02 EEPROM | P1.3–P1.4（I2C） |
| 16×16 LED 点阵 | P2.1–P2.3 → 74HC595 |
| 蜂鸣器 / 状态 LED | P1.5 / P2.0 |
| 晶振 / 复位 | 11.0592 MHz / RC 复位，5 V 稳压 |

### 文件

`main.c` · `LCD1602.c/h` · `key.c/h` · `eeprom.c/h` · `matrix_led.c/h` · `ds1302.c/h` · `time_log.c/h` · `delay.c/h` —— **8 个模块，驱动与业务分离**。

## 2. `lanqiao-mcu/` — 蓝桥杯单片机赛道

**成绩**：第十七届蓝桥杯大赛（电子赛）单片机设计与开发赛道 **国家三等奖 / 新疆赛区一等奖**。

**工程结构**（`17376123/`，17376123 为参赛号）：

```
Driver/          User/
├── ds1302.c/h   ├── main.c
├── ds18b20.c/h  └── 17376123.uvproj
├── init.c/h
├── key.c/h
├── led.c/h
├── relay.c/h
├── seg.c/h
└── timer.c/h
```

**这是标准的竞赛工程结构：`Driver/` 放外设驱动，`User/` 放业务逻辑**——赛场上可以直接把常用驱动当模板拼装，不必从零写。

**覆盖的外设**：DS1302（三线 RTC）、DS18B20（单总线温度传感器，微秒级时序）、IIC、OneWire、数码管动态扫描、继电器、LED、按键、定时器。

> **备赛方法**：我把高频外设封装成可复用模板（"大模板合集"），并在赛后做了完整复盘（"17 省复盘"目录）。这部分方法论性的资料属于个人学习笔记，未随仓库公开。

## 3. `microcomputer-lab/` — 微机原理与应用（51 汇编实验）

《微机原理及应用》8 学时实验，**纯 8051 汇编**（Keil C51 开发环境，普中 51 单片机 A7 开发板）。

| 实验 | 目录 | 内容 |
|---|---|---|
| 实验一 | `微机实验一/` | **LED 灯**：共阳极接法（低电平点亮），P2 口控制，含交通灯逻辑 |
| 实验二 | `微机实验二/` | **蜂鸣器**：频率控制发声 |
| 实验三 | `微机实验三/` | **数码管显示**：动态扫描 |
| 实验四 | `微机实验四/` | **键盘扫描**：行列扫描读取按键 |

每个实验保留了两个版本的实现（`trial_N_1`、`trial_N_2`），记录了调试过程中的迭代。

**为什么保留汇编作业**：它证明的是**寄存器级编程能力**——理解 PC、SP、定时器、中断向量、位寻址这些底层机制，而不是"会用 C 就行"。

## 4. `stm32-cube-practice/` — STM32 备赛练习序列

参加电子设计竞赛备赛期间，用 **STM32CubeMX + STM32CubeIDE** 从零配置的 9 个练习工程，构成一条明确的学习曲线：

| 顺序 | 工程 | 练习内容 |
|---|---|---|
| 1 | `blink` | GPIO 输出，点灯 |
| 2 | `hello` | 串口输出，printf 重定向 |
| 3 | `key` | GPIO 输入，按键读取与消抖 |
| 4 | `PWM_light` | 定时器 PWM，呼吸灯 |
| 5 | `motor` | 电机驱动（第一版） |
| 6 | `motor_2` | 电机驱动（第二版，加入调速） |
| 7 | `motor_3` | 电机驱动（第三版） |
| 8 | `serial` | 串口通信协议收发 |
| 9 | `CubeMX` | 综合工程，多外设协同 |

> **说明**：这些是**学习练习工程**，每个只保留了本人编写的 `Core/Src/main.c` 与 CubeMX 配置文件 `.ioc`；HAL 库与 IDE 生成文件已剔除。它们单独看价值有限，但合起来是一条"从点灯到多外设协同"的完整学习轨迹。这也是后来做电赛（K230 视觉伺服云台 + MSPM0G3507）的基础。
